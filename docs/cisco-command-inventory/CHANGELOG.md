# Versions de l'inventaire

## 0.1.0 — 2026-10-27

- Première collecte locale des références officielles IOS/IOS-XE sélectionnées.
- Inventaire d'occurrences documentaires, sans affirmation de support universel.
- Conservation des variantes publiées, modes et événements de release.
- Échantillon vérifié contre des exemples de configuration Cisco.
- Sources, exclusions, anomalies, frontière et lacunes conservées pour audit.
- Outils de reproduction autonomes ; aucun changement au runtime ni aux templates.

Le contrat de données est versionné séparément en `schema_version: 1.0.0`.
Une évolution de cet inventaire documentaire ne change pas la version du parseur.
